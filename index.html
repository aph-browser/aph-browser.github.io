Aph

A Firefox based browser built around workspaces.

Native workspace management, a command palette, tab archiving, and hardened privacy defaults, injected into stock Firefox. No fork. No recompilation.

Download beta View Source on GitHub Install guide

Features

  • Workspaces 1–9 — Alt+Shift+1..9 to jump, ]/[ to cycle, Tab for last-used. Exclusive model: one workspace renders in at most one window.
  • Command palette — workspace actions, tab/bookmark/history/archive search.
  • Tab archive — park tabs away with workspace + container restore and auto-sweep.
  • Tab groups — native tab groups inside workspaces.
  • Container bindings — bind a workspace to a Firefox container; new tabs open there.
  • Privacy defaults — telemetry, health reports, Normandy, and activity-stream telemetry off. Your edits persist (seed-once prefs).
